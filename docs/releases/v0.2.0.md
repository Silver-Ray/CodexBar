CodexBar v0.2.0 改进 Windows 任务栏显示和面板响应，并增加官方模型价格自动更新。

## 新功能与修复

- 自动避开应用图标和 Traffic Monitor。空间不足时折叠为两行，仅显示 5h 和每周剩余额度；悬停显示完整信息，空间恢复后自动展开。完全没有安全空位时提供托盘入口。
- 高 DPI 下按实际像素绘制文字与布局，适配显示缩放变化，减少静止文字模糊。
- 单击额度条打开 Token 用量面板，重复单击恢复已有窗口；双击打开设置。
- 从 OpenAI 官方定价页面自动更新模型与价格，提供离线价格快照和用户手动覆盖。金额为 API 等价估算，不代表订阅账单。
- 任务栏显示使用独立线程，避免设置、菜单和用量面板的操作被 Explorer 关联的输入队列阻塞；已有用量窗口使用异步恢复。
- 改进开始菜单、系统搜索和时间菜单打开期间的显示稳定性，以及 Explorer 重启后的显示窗口恢复。
- 补齐透明子窗口所需的 Windows 兼容性声明，保持任务栏原生绘制可见。
- 构建先使用临时目录，再替换发布文件，允许终端保持在发布目录中。

## 下载与使用

下载 `CodexBar-Windows-x64.zip`，解压后运行 `CodexBar/CodexBar.exe`。请保留完整文件夹；更新前退出旧版。

`CodexBar-Windows-x64.zip.sha256` 用于校验 ZIP 完整性。此版本仍未进行商业代码签名，首次运行可能显示 Windows SmartScreen 提示。

## 验证

Windows CI 运行全部单元测试、源码编译、PyInstaller 构建、第三方许可证收集和发布隐私审计，通过后自动上传 ZIP 与 SHA-256 文件。
