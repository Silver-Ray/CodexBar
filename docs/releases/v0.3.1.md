## 修复：额度查询中断时整条任务栏显示 ERR

- 连接中断、超时及部分临时 HTTP 服务错误时，对只读额度请求最多尝试 3 次，间隔 1 秒、2 秒。OAuth 刷新请求不重复提交。
- 已成功查询过的额度在刷新失败时继续显示，百分比标记 `*`，完整视图显示异常与上次成功时间；每分钟重试，成功后自动恢复。
- 首次失败分别显示 `NET`、`TLS` 或具体 HTTP 状态，便于区分网络、证书和接口问题；登录失效继续显示 `AUTH` / `RELOGIN`。
- 切换、清除账号及登录失效时清除旧额度；刷新期间保留异常标记，避免把旧数据误认为实时数据。
- 新增 `--check-network <报告路径>`，直接检查 EXE 的网络运行时；报告不包含账号、凭据、代理地址或接口响应正文。
- 保留 v0.3.0 的 Codex Desktop SSH 会话用量、数据来源选择与任务栏折叠显示功能。
