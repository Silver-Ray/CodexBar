## 新增：Codex Desktop SSH 远程会话用量

- 用量面板新增“数据来源”，可选择本机及 Codex Desktop/OpenSSH 配置中的远程主机。
- 查看远程主机每个会话的每日 token、输入/缓存/输出/推理分项、模型、目录、消息数和 API 等价花费；支持周/月/年趋势。
- 复用已有 SSH 用户、密钥、端口和跳板配置。远程 Linux/macOS 主机需 Python 3.8+ 和 Codex 日志，本机需 OpenSSH Client 及 SSH 密钥登录。
- 后台读取，30 秒超时，60 秒缓存；断线保留并明确标注旧数据，加载时可返回本机，切换来源不会混用延迟返回的数据。
- 只读访问远程日志，不安装远程组件；不复制 OAuth 凭据、消息正文或工具输出。统计缓存只保存在本机临时目录，正常关闭面板时清理。
- 所有日期按本机 Windows 时区统计；各主机独立展示，任务栏今日 token 继续统计本机。

## 验证

- 260 项自动测试，包括跨日累计快照差分、重复快照、子会话回放、SSH 超时、断线缓存和数据源隔离。
- 实机 SSH 主机及 WebView 测试：远程会话排行、年度趋势、断线缓存与返回本机通过。
- Windows x64 便携包由 CI 构建，附带 SHA-256 校验文件；下载后完整解压并运行 `CodexBar/CodexBar.exe`。
